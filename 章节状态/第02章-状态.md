# 第2章状态

## 本章功能与核心问题

本章完整建立第一个核心模式 `XW`，回答：当对象不变时，怎样用同一套参数规则重组每个对象的特征？

```text
X: n × d
W: d × k
XW: n × k
```

核心语义是：保留对象轴 `n`，汇总旧特征轴 `d`，生成新特征轴 `k`。第 `i` 个对象的新表示只读取 `X[i, :]`，不同对象不会在 `XW` 中直接混合。

## 已确定内容

元素展开采用：

```text
Y[i, r] = sum over j of X[i, j] * W[j, r]
```

应用不按模型名称罗列，而按输出轴统一：`k = 1` 表示打分或预测，`k = c` 表示多维输出，`k = h` 表示新的隐藏表示。`H = sigma(XW + b)` 仍是逐对象特征变换。

## 内容与教学边界

本章解释 `y_hat = Xw` 表达什么，不讲怎样选择最优 `w`，后者由第5章回收。可以出现连续特征变换，但不展开完整神经网络；只说明表示维度改变，不提前讲 PCA 或 SVD。

与 `AX` 的对照用于划清职责：`XW` 改变描述方式，`AX` 改变信息来源；不在本章深入讲信息聚合。

## 衔接关系

承接第1章阅读流程。第5章从本章的 `y_hat = Xw` 继续追问最优 `w`；第6章在 PCA 语境回收 `XW` 作为低维坐标变换；第7章把连续 `XW` 读成完整信息流。结尾从对象表示引向第3章的关系构造。
