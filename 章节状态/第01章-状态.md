# 第1章状态

## 本章功能与核心问题

本章建立全书的“公式阅读操作系统”，回答：一个矩阵表达式究竟在对谁做什么？矩阵被视为带有轴语义的数据结构，而不是无语义的数字表。

统一阅读动作是：

```text
标轴语义
-> 标形状
-> 检查相乘接口的数量与语义
-> 展开元素
-> 找求和维度
-> 判断保留与新生成的维度
-> 自然语言翻译
-> 必要时绘制信息流
```

本章建立“维度正确，不等于语义正确”的诊断原则，并只初步对照：

```text
XW：沿特征轴求和，保留对象轴
AX：沿来源对象轴求和，保留特征轴
```

## 内容与教学边界

以学生—课程等直观数据表和少量表达式反复训练同一套动作。`XW` 与 `AX` 仅用于建立求和轴差异；`XX^T` 与 `X^T X` 可作为轴角色变化的短例，但不展开关系类型、相似度或归一化。

不扩展为传统线性代数复习章，不系统讲行列式、逆矩阵、秩、线性无关等内容。全章应少列概念、多做阅读与诊断动作，不提前讲完第2—4章。

## 衔接关系

本章方法在全书反复调用，并在第8章被反向用于设计。结尾将 `XW` 作为下一章入口；`AX` 只作对照和第4章预告。

## 当前状态与下一步

正文已完成第一轮全书统一修订，`XW` 与 `AX` 已控制在求和轴差异的初步对照范围。下一步通过基础轴标注、元素展开和语义诊断练习检验阅读流程，并设计必要的轴与接口图示。
