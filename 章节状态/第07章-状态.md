# 第7章状态

## 本章功能与核心问题

本章把局部矩阵动作整合为完整模型的信息流阅读，回答：面对多步复杂公式，怎样拆出中间结果，识别每一步改变的轴和对象交互，最后恢复整体语义？

统一拆解流程是：

```text
切分子表达式
-> 标中间形状
-> 标轴语义
-> 识别基本动作
-> 检查信息来源
-> 串成整体信息流
```

## 已确定内容

全章限定为三个受控案例。前馈网络用于校准连续 `XW` 阅读，分类输出并入该案例。自注意力是完整合成主案例：

```text
Q = XW_Q
K = XW_K
V = XW_V
S = QK^T
A = softmax(S / sqrt(d_k))
O = AV
```

其中 `d_k` 是 query/key 的匹配特征维度，softmax 沿键对象轴进行，使每个查询对象在候选键对象之间分配读取权重。多头注意力只说明多组相同信息流的并行视角。图神经网络用 `H = sigma(AXW)` 回收对象聚合与特征变换的组合，`AXW` 不另设重复小节。

## 内容与教学边界

本章不是模型知识介绍，而是矩阵表达式解剖。只保留服务于形状、轴、关系和信息流阅读的模型细节，不讲训练、反向传播、优化、Transformer 完整架构或 GNN 算法谱系，不增加其他模型案例。

本章主要综合第1—4章；第5—6章提供表达能力和表示结构意识，但不为了形式闭环强行植入未实际使用的投影或 SVD。

## 衔接关系
