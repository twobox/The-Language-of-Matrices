# 第5章状态

## 本章功能与核心问题

本章从信息流转向模型表达能力，回答：当目标 `y` 不在 `Xw` 能表达的集合中时，怎样选择 `w` 得到最佳近似？

核心因果链是：

```text
Xw 的可表达集合
-> y 无法完全表达
-> 用残差距离定义“最好”
-> 在列空间中寻找投影
-> 残差与列空间正交
-> X^T(y - Xw) = 0
-> X^T Xw = X^T y
```

## 已确定内容

必须先讲几何和语义，再讲代数。正规方程的核心解释是：残差中不再含有任何能被 `X` 的列方向解释的成分。闭式解只作为特定可逆条件下的结果，不作为起点或核心记忆对象。

线性回归作为贯穿语境融入整条链，不另设模型介绍。多输出只推广“在给定列空间中近似多个目标”的思想，并为矩阵近似建立接口。

## 内容与教学边界

列空间、残差、投影、最小二乘、正交和正规方程不是并列知识点，而是一个问题的连续解释。正文不扩展到梯度下降、正则化、泛化误差、统计推断或求逆技巧。

`X^T X` 在本章表示把“残差与每个特征方向正交”同时写出；可回扣第3章，但不重复特征关系的首讲。不提前深入 SVD。
