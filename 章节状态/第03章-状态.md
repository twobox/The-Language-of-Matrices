# 第3章状态

## 本章功能与核心问题

本章回答“关系矩阵从哪里来”，完成从对象表示到对象关系、特征关系或跨集合匹配的转换。阅读关系矩阵时的首要问题是：一个元素连接了哪两个实体？

```text
X: n × d
XX^T: n × n       对象 × 对象
X^T X: d × d      特征 × 特征
QK^T: n × m       查询对象 × 键对象
```

## 已确定内容

学生—课程案例用于对照 `XX^T` 与 `X^T X`；用户—商品或查询—候选案例用于说明关系矩阵不必为方阵。`QK^T` 中的行轴是查询对象，列轴是键对象或候选对象；只有对应的 value 随后被读取时，候选对象才同时承担信息来源角色。

本章区分对称关系、方向关系和原始关系分数，并说明原始分数不一定能直接作为聚合权重。

## 内容与教学边界

本章只讲关系如何构造和解释。相似度与距离只讲改变关系含义所需的最小内容，不扩展为度量或核方法大全。归一化只建立“原始关系分数与可用聚合权重不同”的接口；为何沿来源轴归一化由第4章讲解。

`QK^T` 不扩展为完整注意力，图邻接矩阵不展开图传播。

## 衔接关系

承接第2章的对象—特征表示，第4章使用本章构造或给定的关系进行聚合。`QK^T` 在第7章与 `AV` 合成完整注意力信息流。`X^T X` 在第5章作为正交条件的代数结构被调用，在第6章作为特征侧主导模式被调用，均不重复本章的关系语义首讲。
