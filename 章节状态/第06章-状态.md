# 第6章状态

## 本章功能与核心问题

本章是以 SVD 为主线的结构发现章，回答：复杂矩阵能否由少数“对象方向—强度—特征方向”重建，并在低秩限制下保留主要信息？

```text
稳定方向与结构强度
-> XX^T 和 X^T X 的两侧主导模式
-> SVD
-> 秩1成分叠加
-> 截断 SVD
-> 低秩最佳近似
-> PCA 与潜在因素的语义出口
```

## 已确定内容

特征向量与特征值只作为理解稳定模式和结构强度的桥梁，不发展为手工求解专题。SVD 按轴解释：

```text
X: 对象 × 特征
U: 对象 × 潜在方向
Sigma: 潜在方向 × 潜在方向
V^T: 潜在方向 × 特征
```

同时使用秩1叠加读法：

```text
X ≈ sigma_1 * u_1 v_1^T + ... + sigma_k * u_k v_k^T
```

PCA 回扣 `Z = XW` 的低维表示语义；潜在因素说明低秩成分可能对应隐藏结构，但不承诺必然可解释。

本章所说的低秩“最佳近似”明确限定为最小化平方重建误差，即 Frobenius 范数意义下的最佳近似。PCA 只在建立数据中心化这一必要前提后引入，并说明中心化数据的主成分方向与 SVD 右奇异方向的关系；协方差只讲支撑该联系所需的最小语义。

## 内容与教学边界

全章不把特征值、SVD、PCA、推荐分解写成四套平行教程。主干始终是 SVD 与低秩近似；PCA 和潜在因素只作为同一结构的两种应用解释。不以特征方程、手算分解、算法实现或降维方法罗列为主。

第5章是在给定空间中近似目标，第6章是在低秩矩阵集合中近似原矩阵，并同时发现表示空间。

## 衔接关系

承接第5章的最佳近似，并回收第3章的 `XX^T`、`X^T X` 和第2章的 `XW`，但分别赋予主导模式与低维坐标的新作用。第7章不强行把 SVD 塞进模型案例；第8章在表达能力或低维表示的设计选择中调用本章。
