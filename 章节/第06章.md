# 第6章 特征值、SVD与低维结构

## 6.1 为什么要用少数方向解释复杂数据

上一章讨论了一个受限的近似问题。那里的 `X` 是固定样本上的设计矩阵，所有预测 `Xw` 都被限制在 `Col(X)` 中；当目标 `y` 位于空间之外，我们在这个给定空间里寻找最近点。

本章切换 `X` 的角色：被研究的矩阵不再只是规定预测空间的设计矩阵，而是需要被近似、分解和重建的数据本身。为避免两个角色混淆，本章改用 `D` 表示它。假设：

```text
D: 学生 × 课程
D: n × d
```

第5章若以 `Q` 表示固定可表达空间的正交标准基，得到 `Y_hat = Q Q^T Y`；本章则要从 `D` 自身选择一个低维空间，并形成 `D_k = D V_k V_k^T`。前者是在固定空间中选择投影点，后者还要选择用于投影的空间。

表面上，每名学生由 `d` 门课程成绩描述。但这些课程可能并不代表 `d` 个彼此独立的变化方向。数学与物理成绩也许经常共同升降，多门语言类课程也可能体现相近的能力。虽然矩阵有很多列，数据的主要差异却可能集中在少数几个特征组合上。

类似现象出现在许多矩阵中。用户—商品评分矩阵可能由少数偏好因素主导；一组图像的像素很多，主要变化却可能集中在轮廓、姿态或亮度等少数方向；词语与上下文的共现矩阵很大，但某些语义模式可能反复出现。

这促使我们提出三个问题：

```text
哪些方向承载了数据中最强的结构？
每个方向有多重要？
能否只保留少数方向，重建原矩阵的主要信息？
```

如果答案是肯定的，那么一个形状很大的矩阵未必需要同样多的独立成分才能解释。所谓低维结构，不是说原矩阵真的少了行或列，而是说它的主要变化可以由较少的方向组织起来。

本章将以奇异值分解，也就是 SVD，为主线。特征向量和特征值先帮助我们理解“稳定方向”和“结构强度”；`DD^T` 与 `D^T D` 让我们分别观察对象侧和特征侧模式；SVD 再把两侧方向通过奇异值配对起来。截断分解后，我们会得到一个低秩近似，并明确它在平方重建误差下为何是最佳的。

这里的“方向”并不等同于某一列原始特征。它通常是多个原始特征的组合；“少数方向”也不意味着我们已经自动获得可命名、可解释的现实因素。矩阵分解先提供结构，解释还需要结合数据来源与任务语境。

## 6.2 稳定方向与结构强度：特征向量和特征值

设 `A` 是一个实方阵。一般向量经过 `A` 作用后，方向和长度都可能改变。本节只讨论实特征对：非零实向量 `v` 与实数 `lambda` 满足：

```text
Av = lambda * v
```

此时 `v` 称为 `A` 的特征向量，`lambda` 称为对应的特征值。一般实方阵还可能出现复特征值与复特征向量，本章不展开；数据主线实际使用的是 `DD^T` 和 `D^T D`，它们都是实对称半正定矩阵，具有非负实特征值和一组正交的实特征向量。

这条式子的语义很直接：矩阵 `A` 作用在 `v` 上之后，结果仍沿着 `v` 的方向，只是被 `lambda` 缩放。若：

```text
lambda > 1
```

该方向被放大；若：

```text
0 < lambda < 1
```

该方向被缩小；若 `lambda < 0`，方向还会翻转；若 `lambda = 0`，该方向被压到零向量。

因此，可以把特征向量看作矩阵作用下的稳定方向，把特征值看作该方向的缩放强度。这里的“稳定”只指方向在作用后保持共线，不表示系统在时间意义上一定稳定。

这个概念为什么能帮助理解数据结构？关键在于我们会把它应用到：

```text
DD^T
D^T D
```

这两个矩阵都是实对称半正定的，因为对任意实向量 `z`，都有 `z^T D^T Dz = ||Dz||^2 >= 0`，对象侧同理。因此它们的特征值非负，并可选择一组互相正交的实特征向量；较大的特征值对应更强的模式。

以特征侧矩阵为例：

```text
G = D^T D
G: 特征 × 特征
```

若：

```text
Gv = lambda * v
```

那么 `v` 是特征空间中的一个组合方向。它不是某一门课程，而是一组课程权重。把对象表示投到这个方向上：

```text
Dv
```

会得到所有对象在该组合方向上的坐标。

这个方向的强度可以从下面的等式看出：

```text
||Dv||^2
= v^T D^T Dv
= lambda * ||v||^2
```

若把 `v` 规范为单位长度：

```text
||v|| = 1
```

就有：

```text
||Dv||^2 = lambda
```

因此，在 `D^T D` 中，特征值 `lambda` 衡量数据沿特征方向 `v` 所具有的平方强度。特征值越大，所有对象投到该方向后的总体幅度越大。

本章不讨论怎样通过特征方程手算 `v` 和 `lambda`。我们使用它们，是为了建立一种结构语言：复杂数据中可能存在若干正交方向，每个方向都有自己的强度。接下来，SVD 会把这种语言推广到任意形状的 `D`。

## 6.3 从 `XX^T` 与 `X^T X` 观察两侧主导模式

第3章已经说明：

```text
D: 对象 × 特征
DD^T: 对象 × 对象
D^T D: 特征 × 特征
```

当时我们关注的是关系矩阵的轴。本章进一步问：这两个关系矩阵中最强的稳定模式是什么？

设 `v` 是 `D^T D` 的一个单位特征向量：

```text
D^T Dv = lambda * v
```

如果 `lambda > 0`，定义：

```text
sigma = sqrt(lambda)
u = Dv / sigma
```

由于 `v` 是单位向量：

```text
||u||^2
= ||Dv||^2 / sigma^2
= (v^T D^T Dv) / lambda
= lambda / lambda
= 1
```

所以 `u` 也是单位向量，并且：

```text
Dv = sigma * u
```

进一步有：

```text
D^T u
= D^T Dv / sigma
= lambda * v / sigma
= sigma * v
```

以及：

```text
DD^T u
= D(sigma * v)
= lambda * u
```

也就是说，同一个正特征值 `lambda` 同时连接了两侧模式：

```text
v：特征侧方向
u：对象侧方向
sigma：两者之间的缩放强度
lambda = sigma^2
```

这两条奇异向量关系描述一个往返过程：

```text
特征方向 v
--D-->
对象方向 u

对象方向 u
--D^T-->
特征方向 v
```

其中缩放系数都是 `sigma`。

在学生—课程矩阵中，`v` 可以是课程特征的一种组合，表示“沿哪些课程共同变化”；`u` 描述所有学生在这项组合模式上的对象侧形态。二者不是两套无关的分析，而是同一个矩阵结构在特征侧和对象侧的两个视角。

`DD^T` 与 `D^T D` 具有相同的正特征值，包括重数。对 `D^T D` 的每个正特征值对应的单位特征向量，都能按上述方式得到一对左右方向。零特征值则直接描述零空间：

```text
D^T Dv = 0  <=>  Dv = 0
DD^T u = 0  <=>  D^T u = 0
```

所以 `D^T D` 的零特征方向构成 `Null(D)`，`DD^T` 的零特征方向构成 `Null(D^T)`。这些方向被映到零，不能用于除以 `sigma`，也不出现在紧致 SVD 的非零成分中。非零奇异值的数量正是：

```text
r = rank(D)
```

按强度从大到小排列：

```text
sigma_1 >= sigma_2 >= ... >= sigma_r > 0
```

其中 `r` 是矩阵 `D` 的秩，也就是独立非零结构成分的数量。由秩—零度关系还可读出：

```text
dim Null(D)   = d - r
dim Null(D^T) = n - r
```

也就是说，秩计数被保留的非零方向，零空间计数被完全压到零的方向。若只有前几个 `sigma` 很大，后面的很小，说明主要结构集中在少数成分上；若许多 `sigma` 都相近，则数据更难被少数方向概括。

这就引出了奇异值分解。它不要求 `D` 是方阵，而是直接把这些对象侧方向、特征侧方向和对应强度组织成三个矩阵。

## 6.4 SVD：对象方向、强度与特征方向

对任意实矩阵：

```text
D: n × d
```

奇异值分解可以写成：

```text
D = U Sigma V^T
```

为了突出有效结构，先采用紧致 SVD。若 `D` 的秩为 `r`，则：

```text
U: n × r
Sigma: r × r
V: d × r
V^T: r × d
```

紧致形式只保留 `r` 个正奇异值及其左右方向。完整 SVD 则把 `U` 和 `V` 分别补成 `n × n` 与 `d × d` 的正交矩阵，并使用 `n × d` 的矩形 `Sigma_full`；新增方向对应零奇异值与两侧零空间。两种形式重建同一个 `D`，本章后续使用更紧凑的紧致形式。

沿轴语义阅读：

```text
U: 对象 × 潜在方向
Sigma: 潜在方向 × 潜在方向
V^T: 潜在方向 × 特征
```

相乘后：

```text
(对象 × 潜在方向)
(潜在方向 × 潜在方向)
(潜在方向 × 特征)
-> 对象 × 特征
```

`U` 的列是左奇异向量：

```text
u_1, u_2, ..., u_r
```

它们是对象侧的正交单位方向。`V` 的列是右奇异向量：

```text
v_1, v_2, ..., v_r
```

它们是特征侧的正交单位方向。`Sigma` 是对角矩阵，对角线上放置奇异值：

```text
sigma_1, sigma_2, ..., sigma_r
```

按从大到小排列。

每一对左右奇异向量都可以同时乘以 `-1`，对应秩1重建项不变；若某个奇异值重复，对应左右奇异子空间内还可以共同更换正交基。因此，稳定的结构有时是一个子空间，而不是带固定正负号的某一根向量。

对于每一对方向，都有：

```text
Dv_t = sigma_t * u_t
D^T u_t = sigma_t * v_t
```

下标 `t` 表示第 `t` 个结构成分。右奇异方向 `v_t` 经过 `D` 映射到对象侧方向 `u_t`，奇异值 `sigma_t` 表示该成分的强度。

还可以把分解读成三个连续动作。给定特征空间中的任意输入向量 `x`，矩阵乘法：

```text
Dx = U Sigma V^T x
```

可以理解为：

```text
V^T：把输入分解到右奇异方向上
Sigma：按奇异值缩放各方向
U：在对象侧方向中重新组合
```

不过，本书更关心数据矩阵 `D` 本身如何被这些方向构成，而不是把 SVD 只看成一个线性变换流程。为此，需要把矩阵乘积展开为若干个秩1成分。

## 6.5 从秩1成分叠加到低秩重建

由于 `Sigma` 只有对角线上非零，SVD 可以写成：

```text
D
= sigma_1 * u_1 v_1^T
+ sigma_2 * u_2 v_2^T
+ ...
+ sigma_r * u_r v_r^T
```

每一项：

```text
sigma_t * u_t v_t^T
```

都是一个 `n × d` 矩阵。外积：

```text
u_t v_t^T
```

把对象侧模式 `u_t` 与特征侧模式 `v_t` 配对。它的元素为：

```text
(u_t v_t^T)[i, j]
= u_t[i] * v_t[j]
```

乘上奇异值后，第 `t` 个成分对原矩阵元素的贡献是：

```text
sigma_t * u_t[i] * v_t[j]
```

因此，一个数据元素可以被写成所有结构成分贡献的总和：

```text
D[i, j]
= sum over t = 1 to r of
  sigma_t * u_t[i] * v_t[j]
```

这条式子给潜在方向一个很具体的含义：

```text
u_t[i]：对象 i 在第 t 个对象侧模式中的位置
v_t[j]：特征 j 在第 t 个特征侧模式中的位置
sigma_t：第 t 个模式对整体矩阵的重要程度
```

为什么 `u_t v_t^T` 称为秩1成分？因为它的每一列都是 `u_t` 的倍数，每一行都是 `v_t^T` 的倍数；所有列只沿一个对象方向变化，所有行只沿一个特征方向变化。单个成分结构极其简单，多个秩1成分叠加后却可以重建复杂矩阵。

如果奇异值按从大到小排列，前几个成分通常承载较大的平方能量。矩阵的 Frobenius 范数满足：

```text
||D||_F^2
= sigma_1^2
+ sigma_2^2
+ ...
+ sigma_r^2
```

所以 `sigma_t^2` 可以理解为第 `t` 个正交成分对总平方规模的贡献。

这让“保留主要信息”具有了可计算含义。若前 `k` 个奇异值的平方和占总平方和的大部分，就可以尝试只保留这些成分：

```text
D_k
= sigma_1 * u_1 v_1^T
+ ...
+ sigma_k * u_k v_k^T
```

其中为获得真正的降秩近似，取：

```text
1 <= k < r
```

因为前 `k` 个奇异值均为正，`D_k` 的秩恰为 `k`。若允许 `k = 0`，得到零矩阵；若 `k >= r`，则已可完整重建 `D`，不再是有损截断。

## 6.6 截断 SVD：低秩意义下的最佳近似

只保留前 `k` 个奇异成分，称为截断 SVD。用矩阵形式写：

```text
D_k = U_k Sigma_k V_k^T
```

其中：

```text
U_k: n × k
Sigma_k: k × k
V_k: d × k
```

这不仅是一种直观压缩。在 Frobenius 范数意义下，它具有最佳近似性质：在所有与 `D` 同形、秩不超过 `k` 的矩阵 `B` 中，`D_k` 是使平方重建误差最小的一个解：

```text
D_k ∈ argmin over
B ∈ R^(n × d), rank(B) <= k
of ||D - B||_F^2
```

这里 `argmin` 仍是集合语义；当最佳矩阵不唯一时，`D_k` 表示其中由当前截断方向构造出的一个。

并且误差为被丢弃奇异值的平方和：

```text
||D - D_k||_F^2
= sigma_(k+1)^2
+ ...
+ sigma_r^2
```

这就是 Eckart—Young—Mirsky 定理在 Frobenius 范数下的结论。本章不证明完整定理，但可以理解其结构原因：SVD 把 `D` 分解成彼此正交的秩1成分；若只看这些正交成分，丢掉较小成分比丢掉较大成分造成的平方误差更小。完整定理还保证，任意其他秩不超过 `k` 的方向组合也不能得到更小误差。

这里需要区分三类非唯一性。

第一，单个奇异向量的表示非唯一：每对 `u_t, v_t` 可同时翻转符号；重复奇异值对应的左右子空间还可共同更换正交基。这些变化不一定改变完整矩阵或相应的成分总和。

第二，最佳低秩矩阵本身可能非唯一。对 `1 <= k < r`，若截断边界满足：

```text
sigma_k > sigma_(k+1)
```

最佳秩不超过 `k` 的矩阵唯一；若 `sigma_k = sigma_(k+1)`，边界跨过重复奇异值子空间，可以选取不同的 `k` 维部分，得到不同但误差相同的最佳矩阵。

第三，后文一般因素分解 `PQ^T` 即使重建矩阵已经固定，因素坐标仍可经过任意可逆变换而不改变乘积。这种坐标非唯一比 SVD 的符号或重复子空间自由度更大。

第5章与这里的“最佳近似”具有相同精神，但可选择的集合不同：

```text
第5章：给定设计矩阵 X 与固定空间 Col(X)，
        寻找最接近目标 y 或 Y 的投影

第6章：在所有与 D 同形、秩不超过 k 的矩阵中，
        寻找最接近数据矩阵 D 的矩阵
```

公式桥梁更直接。若 `Q` 是第5章固定空间的正交标准基，则：

```text
Y_hat = Q Q^T Y
```

而截断 SVD 满足：

```text
D_k
= U_k Sigma_k V_k^T
= D V_k V_k^T
= U_k U_k^T D
```

`Q Q^T` 投到给定空间；`V_k V_k^T` 与 `U_k U_k^T` 则投到从 `D` 选择出的右、左主导子空间。固定空间中的最近点与选择空间后的低秩重建，都由正交投影实现，但后者还优化了空间的选择。

奇异值谱可以帮助判断低秩近似是否合适。若：

```text
sigma_1, ..., sigma_k
```

远大于后续奇异值，保留前 `k` 个成分可能已经覆盖主要平方规模；若奇异值缓慢下降，没有明显间隔，那么选择较小的 `k` 会丢失更多结构。

但“平方规模较大”不自动等于“任务上最重要”。某个数值较弱的方向也可能与少数关键对象、罕见事件或预测目标有关。截断 SVD 优化的是整体 Frobenius 重建误差，不知道具体任务的代价。因此，`k` 的选择既要看奇异值，也要结合用途。

## 6.7 PCA 与潜在因素：同一结构的不同语义

SVD 可以通向多种应用解释。本节只讨论两种：PCA 关注对象在低维坐标中的表示，潜在因素分解关注两个实体轴怎样通过共同隐藏维度发生匹配。它们都使用低维结构，却回答不同问题。

### PCA：在中心化数据中寻找主要变化方向

设：

```text
D: 对象 × 特征
```

标准 PCA 通常先对每个特征减去它在所有对象上的均值；本章所说的 PCA 均指这种中心化 PCA。这里假设 `n > 1`，以便后文样本协方差的分母 `n - 1` 有定义。记原数据的特征均值行为向量为 `mu^T: 1 × d`，中心化后的矩阵为：

```text
D_centered
```

中心化可写为：

```text
D_centered = D - 1_n mu^T
```

它使每一列的均值为0，从而让“变化方向”围绕数据中心定义，而不是把整体偏移误当成主要方向。由于 `1_n^T D_centered = 0`，中心化还带来秩上界：

```text
rank(D_centered) <= min(n - 1, d)
```

因此可用的非零主成分数最多为 `min(n - 1, d)`。

对中心化矩阵做 SVD：

```text
D_centered = U Sigma V^T
```

`V` 的右奇异向量就是主成分方向。若保留前 `k` 个方向：

```text
V_k: 特征 × 主成分
V_k: d × k
```

低维坐标为：

```text
Z = D_centered V_k
Z: 对象 × 主成分
```

根据 SVD：

```text
Z = U_k Sigma_k
```

低维坐标可以重建中心化数据的秩 `k` 近似：

```text
D_centered,k
= Z V_k^T
= U_k Sigma_k V_k^T
```

若要回到原始数据坐标，还需要把均值加回：

```text
D_hat_k = Z V_k^T + 1_n mu^T
```

所以 PCA 对中心化数据使用线性低秩重建，而对原始数据得到的是经过均值平移的仿射重建；只写 `ZV_k^T` 尚未回到原坐标。

这里回收了第2章的 `XW` 模式：PCA 的 `Z = D_centered V_k` 也是逐对象特征变换，只是变换矩阵不是任意参数，而是由中心化数据的前 `k` 个右奇异方向组成。

若用中心化数据构造特征侧矩阵：

```text
D_centered^T D_centered
```

它的特征向量同样是 `V` 的列，特征值是奇异值平方：

```text
lambda_t = sigma_t^2
```

采用样本协方差约定时：

```text
Cov
= D_centered^T D_centered / (n - 1)
```

第 `t` 个主成分的样本方差为：

```text
sigma_t^2 / (n - 1)
```

若采用总体约定，则分母为 `n`。分母会改变方差数值，却不改变主成分方向。当中心化数据的总平方规模为正，即 `sum over s of sigma_s^2 > 0` 时，解释方差比例在两种约定下都为：

```text
sigma_t^2 / sum over s of sigma_s^2
```

若中心化矩阵为零矩阵，总方差为零，这个比例没有定义，也不能依据方差大小选出唯一的主方向。在总方差为正时，PCA 中“解释了较多方差”表示该方向对中心化矩阵的 Frobenius 平方规模贡献较大；前 `k` 个主成分的低维坐标保留了截断 SVD 所保留的主要平方结构。

### 潜在因素：通过共同隐藏维度解释两个实体轴

考虑用户—商品评分矩阵：

```text
R: 用户 × 商品
```

若它近似为低秩，可以写成：

```text
R ≈ U_k Sigma_k V_k^T
```

也常把奇异值的缩放分配到两侧，例如令：

```text
P = U_k Sigma_k^(1/2)
Q = V_k Sigma_k^(1/2)
```

就有更一般的形式：

```text
R ≈ P Q^T
```

其中：

```text
P: 用户 × 潜在因素
Q: 商品 × 潜在因素
```

元素展开：

```text
R_hat[i, j]
= sum over t of P[i, t] * Q[j, t]
```

其中 `i` 是用户，`j` 是商品，`t` 是潜在因素。

这与第3章的跨集合匹配结构相呼应：用户和商品先拥有同一潜在因素轴上的表示，再通过内积产生匹配分数。低秩假设认为，原本庞大的用户—商品矩阵主要由较少的共同因素组织。

我们可以尝试把某些因素解释为对不同内容类型的偏好、价格敏感度或其他隐藏属性，但这种命名不是分解自动提供的。对一般的 `PQ^T`，非唯一性比 SVD 的符号翻转更大：若使用 `k` 个潜在因素，则对任意可逆矩阵：

```text
A: k × k
```

可以同时把两侧因素变换为：

```text
P_new = P A              : 用户 × k
Q_new = Q A^(-T)         : 商品 × k
```

仍然有：

```text
P_new Q_new^T = P Q^T
```

因此，潜在因素可以发生旋转、缩放和混合而不改变重建。除非加入正交、非负、稀疏等额外约束，单个因素通常没有唯一意义。即使低秩重建很好，单个潜在方向也未必具有稳定的现实名称。

这里先把 `R` 当作完整矩阵解释低秩语义。实际推荐数据通常有大量未观测条目，不能简单把“未知”当作真实的零；实际模型往往只在已观测位置上拟合，并可能加入偏置和正则化，本章不展开这些算法细节。

因此，PCA 与潜在因素并不是与 SVD 并列的三套无关方法。它们是同一低维结构的不同语义出口：

```text
PCA：强调对象在主导特征方向上的低维坐标
潜在因素：强调两个实体轴通过共同隐藏维度形成低秩矩阵
```

## 6.8 解释、压缩并审慎命名潜在结构

本章主线可压缩为：

```text
D^T Dv_t = sigma_t^2 v_t，DD^T u_t = sigma_t^2 u_t
-> D = U Sigma V^T
-> D = sum over t = 1 to r of sigma_t u_t v_t^T
-> D_k = U_k Sigma_k V_k^T
-> D_k ∈ argmin_{B ∈ R^(n × d), rank(B) <= k} ||D - B||_F^2
```

使用这条链时必须保留条件：`D` 为实矩阵，紧致 SVD 只保留 `r = rank(D)` 个正奇异值；真正降秩时 `1 <= k < r`；截断误差是 `sum over t = k+1 to r of sigma_t^2`。若 `sigma_k > sigma_(k+1)`，最佳低秩矩阵唯一；边界奇异值相等时，最佳矩阵可不唯一。

解释还要守住三条边界。奇异值大只表示对当前矩阵整体平方规模贡献大，不保证对具体任务最重要；PCA 的方向通常是原始特征组合，并要求先中心化，原坐标重建还要加回均值；一般 `PQ^T` 的单个潜在因素可经可逆变换而改变，不能仅凭重建效果获得唯一现实名称。

至此，第5章的固定空间投影：

```text
Y_hat = Q Q^T Y
```

被推进为第6章的选择空间与低秩重建：

```text
D_k = D V_k V_k^T = U_k U_k^T D
```

前六章由此连接起来：特征可以被重组，关系可以被构造，信息可以被聚合，目标可以投到给定空间，数据也可以通过选取主导空间而被低秩近似。

下一章将回到完整机器学习公式，在前馈网络中追踪连续的 `XW`，在注意力中连接 `QK^T` 与 `AV`，在图神经网络中拆解 `AXW`。方法仍然是标注轴、拆出中间结果，并追踪信息沿哪条维度流动。
