# 第7章 完整机器学习模型的矩阵信息流

## 7.1 从局部矩阵动作到完整信息流

前六章有意把矩阵表达式拆成局部动作：

```text
XW：逐对象重组特征
XX^T / X^T X / QK^T：构造关系
AX / AV：按照关系聚合信息
Xw ≈ y：在可表达集合中寻找最佳近似
U Sigma V^T：分解并近似矩阵结构
```

真实公式往往把若干动作嵌套在一起。例如：

```text
Y = C phi(AXW_1 + b)W_2
```

只检查乘法能否进行，还不能回答：`A` 与 `C` 各自连接哪两类对象？`W_1` 与 `W_2` 各自汇总哪条特征轴？`phi` 前后的结果描述谁？输出的一行究竟依赖输入的哪些行？

这就是本章要处理的嵌套问题。这里所说的“完整”，不是完整产品系统、完整训练过程，也不要求一个公式囊括所有机器学习环节。它指一个可闭合解释的模型模块，或一段局部前向信息流：给定输入后，能够逐步说明中间结果如何产生，并一直追踪到该模块的输出。

因此，不同模型模块不必包含同一套阶段。前馈网络主要连续改变特征；自注意力先动态构造关系，再读取信息；图层使用给定或预处理后的图关系完成聚合与变换。完整阅读的标准不是动作齐全，而是实际出现的每一步都能接上。

本章只使用三个受控案例，不讨论训练、反向传播、优化、完整 Transformer 架构或图神经网络谱系。目标是把局部表达式连接成可核验的信息流。

## 7.2 拆解复杂表达式：中间结果、形状与轴

面对嵌套表达式，可以执行六步流程：

```text
切分子表达式
-> 标中间形状
-> 标轴语义
-> 识别基本动作
-> 检查信息来源
-> 串成整体信息流
```

以一个尚未解释其模型名称的表达式为例：

```text
Y = C phi(AXW_1 + b)W_2
```

先按计算依赖切分：

```text
M = AX
Z = MW_1 + b
H = phi(Z)
G = CH
Y = GW_2
```

拆分不是为了增加符号，而是让每个阶段都有可检查的输入和输出。接着不能只标数字，还要为轴命名。假设：

```text
X: 第一组来源对象 × 原始特征
A: 中间目标对象 × 第一组来源对象
W_1: 原始特征 × 隐藏特征
C: 最终目标对象 × 中间来源对象
W_2: 隐藏特征 × 输出特征
```

于是：

```text
M: 中间目标对象 × 原始特征
Z, H: 中间对象 × 隐藏特征
G: 最终目标对象 × 隐藏特征
Y: 最终目标对象 × 输出特征
```

这里默认 `A` 的行所表示的中间目标对象，与 `C` 的列所表示的中间来源对象是同一集合、同一顺序。`b` 沿中间对象轴广播；若这一约定不成立，形状即使碰巧相等，信息流也接不上。

然后识别动作：

```text
AX、CH：沿来源对象轴聚合
MW_1、GW_2：沿旧特征轴变换
+b、phi：不混合对象的逐位置处理
```

最后检查信息来源。两个结果都可能是 `n × h`，但依赖关系可以完全不同：

```text
XW：第 i 行只读取 X 的第 i 行
AX：第 i 行可读取 X 的多行
```

形状只说明接口数量，元素展开才能确定对象是否交互。完成局部检查后，再把动作串成一句有方向的叙述：第一组来源对象先按 `A` 汇入中间对象，特征经过变换和非线性，再按 `C` 汇入最终目标对象，最后生成输出特征。

这套流程只是阅读框架。后面三个案例将分别校准连续特征变换、动态关系读取和给定图关系聚合。

## 7.3 前馈网络：连续的逐对象特征变换

考虑一个两层前馈网络模块：

```text
H = sigma(XW_1 + b_1)
L = HW_2 + b_2
```

设：

```text
X: 对象 × 原始特征
X: n × d
W_1: 原始特征 × 隐藏特征
W_1: d × h
W_2: 隐藏特征 × 类别
W_2: h × c

H: 对象 × 隐藏特征
L: 对象 × 类别
```

偏置分别沿对象轴广播。这里 `i` 表示当前对象，`j` 表示原始特征，`r` 表示隐藏特征，`q` 表示类别。`L[i, q]` 是对象 `i` 对类别 `q` 的分类分数；这里用 `L` 表示分类分数，避免与后文的关系分数混用符号。

两次矩阵乘法分别展开为：

```text
H[i, r]
= sigma(
    sum over j of X[i, j] * W_1[j, r]
    + b_1[r]
  )

L[i, q]
= sum over r of H[i, r] * W_2[r, q]
  + b_2[q]
```

第一步汇总原始特征 `j`，第二步汇总隐藏特征 `r`。两步都保留对象 `i`，没有对其他对象索引求和。分类输出也不是新的矩阵动作，只是把输出特征轴解释为类别。

整段信息流是：

```text
对象 × 原始特征
-> 对象 × 隐藏特征
-> 对象 × 类别分数
```

本节需要校准的只有一个判断：层数增加不等于对象之间发生交互。只要各步都是逐行的 `XW`、偏置和逐元素函数，改变对象 `p` 的输入就不会在这个模块中直接改变另一对象 `i` 的输出。对象交互必须由沿对象轴求和的动作或其他明确的跨对象操作引入，不能从“网络更深”推断出来。

## 7.4 自注意力：从 `Q`、`K`、`V` 到关系构造与信息读取

现在第一次完整连接注意力链。设输入：

```text
X: 词元 × 输入特征
X: n × d_model
```

同一批词元先产生三种角色表示：

```text
Q = XW_Q
K = XW_K
V = XW_V
```

其中：

```text
W_Q, W_K: d_model × d_k
W_V: d_model × d_v

Q: 查询词元 × 匹配特征
K: 键词元 × 匹配特征
V: 来源词元 × value特征
```

这三步都只改变特征，不混合词元。`Q` 与 `K` 共享匹配特征轴，`V` 提供随后真正被读取的内容。

构造原始关系分数：

```text
R = QK^T / sqrt(d_k)
R: 查询词元 × 键词元
R: n × n
```

元素展开：

```text
R[i, p]
= (sum over j of Q[i, j] * K[p, j])
  / sqrt(d_k)
```

`i` 是查询词元，`p` 是键词元，`j` 是匹配特征。即使两条对象轴来自同一批词元，它们承担的角色也不同，所以 `R` 不必对称。缩放项控制进入 softmax 的典型数值尺度，不改变轴语义。

沿键对象轴把分数变为读取权重。用 `s` 表示分母中遍历的另一个键对象位置：

```text
A = softmax(R, along key axis)
A: 查询词元 × 来源词元

A[i, p]
= exp(R[i, p])
  / sum over s of exp(R[i, s])
```

对每个固定查询 `i`，允许来源上的权重和为1。这里键对象的对应 value 随后成为信息来源，因此 `A` 的列轴可在读取阶段称为来源词元轴。

最后聚合：

```text
O = AV
O: 查询词元 × value特征

O[i, r]
= sum over p of A[i, p] * V[p, r]
```

键和值的第 `p` 行对应同一来源位置，但职责不同：`K[p, :]` 参与决定读多少，`V[p, :]` 提供实际读取内容。

完整注意力信息流由此闭合：

```text
X
-> Q = XW_Q, K = XW_K, V = XW_V
-> R = QK^T / sqrt(d_k)
-> A = softmax(R, along key axis)
-> O = AV
```

若某些来源不允许被读取，掩码要在 softmax 前作用于分数：

```text
A = softmax(R + M, along key axis)
```

允许位置的 `M` 可取0，禁止位置视为负无穷。不能先做 softmax 再简单置零，否则保留位置不再按原规则归一化。

还有一个必须显式处理的边界：若某一整行没有任何合法来源，那么该行在掩码后没有可归一化的候选，softmax 没有合法概率解释，数值实现也可能产生未定义结果。模型模块必须另行规定边界策略，例如保证至少一个合法来源、提供专门的回退来源，或绕过该行并产生约定输出；不能把“整行全被屏蔽”当作普通掩码情况。

## 7.5 多头注意力：并行关系视角的最小解释

多头注意力没有引入新的矩阵语义动作。对第 `a` 个头：

```text
Q_a = XW_Q_a
K_a = XW_K_a
V_a = XW_V_a

A_a = softmax(
        Q_a K_a^T / sqrt(d_k_head),
        along key axis
      )
O_a = A_a V_a
```

每个头都重复“特征变换—关系构造—来源归一化—信息聚合”，只是参数不同。多个结果沿特征轴拼接，再做一次特征变换：

```text
O_concat = concat(O_1, ..., O_g)
O_final = O_concat W_O
```

拼接不混合词元；第 `i` 行仍描述同一查询词元，只是并列放入各头产生的特征。不同参数允许各头形成不同读取模式，但公式本身不保证某个头必然对应某种可命名关系。

实现中常把“头”写成额外张量轴。本书将每个头分别写成矩阵，只为突出其信息流与单头相同；遇到高阶张量时，仍应为新增轴命名。

## 7.6 图神经网络：在给定关系上聚合与变换

设：

```text
X: 节点 × 输入特征
X: n × d
A: 目标节点 × 来源节点
A: n × n
W: 输入特征 × 隐藏特征
W: d × h
```

这里的 `A` 不是由字母自动决定的。它至少要有一个明确来源，例如原始邻接表经过方向校准和权重处理后得到，或由外部规则、可学习机制生成。无论来源是什么，进入当前图层时都必须按以下约定读取：

```text
A[i, p]：来源节点 p 对目标节点 i 的权重
```

一个基础图层写成：

```text
H = sigma(AXW)
H: 目标节点 × 隐藏特征
```

展开为：

```text
H[i, r]
= sigma(
    sum over p, j of
      A[i, p] * X[p, j] * W[j, r]
  )
```

来源节点 `p` 与输入特征 `j` 被求和，目标节点 `i` 和隐藏特征 `r` 保留。图层中的对象交互来自 `A`；`W` 只重组特征。

`A` 的三个约定不能省略：

```text
来源：它由什么图、规则或数据生成？
自连接：A[i, i] 是否允许节点读取自己？
归一化：若要加权平均，是否沿每个目标的来源轴归一化？
```

原始邻接矩阵通常只是“是否连接”，不自动等于最终权重矩阵。若采用行归一化，则每个目标节点在合法来源之间分配权重；若采用度数缩放、未归一化求和或可学习权重，信息含义会不同。没有自连接时，图层只读取关系允许的其他来源；需要自身信息时，必须由模型约定明确加入，不能默认补上。

在线性部分，根据结合律：

```text
AXW = A(XW) = (AX)W
```

可以先变换来源特征再聚合，也可以先聚合原始特征再变换。矩阵顺序仍是 `A-X-W`，不能任意交换；若中间插入非线性、归一化或其他操作，两个分组也不再必然等价。

多层图模型模块例如：

```text
H_1 = sigma(A_1 X W_1)
H_2 = sigma(A_2 H_1 W_2)
```

第二个图层可沿连续关系路径读取更远信息，但具体依赖还受 `A_1`、`A_2`、特征变换和非线性影响。这里应称每一步为“图层”，若若干图层共同形成可闭合前向计算，再称为“模型模块”；不要把一个 `AXW` 运算与完整图模型混为一谈。

## 7.7 横向比较：哪些轴改变，哪些对象发生交互

三个案例可压缩为一张对照表：

| 模型模块 | 核心信息流 | 对象是否交互 | 关系来源 | 主要求和轴 |
| --- | --- | --- | --- | --- |
| 前馈网络 | `XW_1 -> sigma -> HW_2` | 否 | 无显式对象关系 | 旧特征轴 |
| 自注意力 | `XW -> QK^T -> softmax -> AV` | 是 | 当前表示动态构造 | 匹配特征轴、来源对象轴 |
| 图层 | `AXW -> sigma` | 是 | 给定、预处理或另行生成的图关系 | 来源节点轴、旧特征轴 |

三者都可能输出 `n × h`，但每一行的依赖范围不同：

```text
XW 的第 i 行：只直接依赖 X 的第 i 行
AV 的第 i 行：依赖 A[i, :] 允许读取的 value 行
AXW 的第 i 行：依赖图关系 A[i, :] 连接的来源节点行
```

因此，隐藏维度从 `d` 变成 `h` 只描述特征轴变化，不能说明对象是否交互。判断对象交互，要找是否沿来源对象轴求和。

还要区分关系如何得到。自注意力的权重随当前输入表示变化；图层中的 `A` 可以固定，也可以由当前数据生成，但正文必须明确说明。只要出现关系矩阵，就检查：行代表谁，列代表谁，是否有自连接，沿哪条轴归一化，后续又沿哪条轴聚合。

第5、6章的近似和低维结构意识仍然提供背景，但不能仅凭隐藏维度较小，就断言一个模型模块执行了最小二乘投影、PCA 或截断 SVD。阅读必须以公式实际出现的目标和约束为依据。

## 7.8 从复杂公式恢复整体信息流

三个案例之后，面对陌生公式不必再把每种熟悉结构完整重讲一遍。更有效的迁移，是先恢复依赖图，再选择最能暴露风险的局部元素式。

考虑一个带并行分支和残差的模块：

```text
H = X + A(XW_V)W_O + phi(XW_1)W_2
```

先提出轴条件，而不是猜模型名称。设：

```text
X: 对象 × 模型特征
A: 目标对象 × 来源对象
XW_V W_O: 对象 × 模型特征
phi(XW_1)W_2: 对象 × 模型特征
```

三条分支只有在对象集合、行顺序和最终特征轴一致时才能相加。随后分别追踪依赖：恒等分支只保留对象自身表示；`A(XW_V)W_O` 先逐对象变换来源内容，再沿来源对象轴聚合；`phi(XW_1)W_2` 只在每个对象内部连续改变特征。一个典型聚合分支元素为：

```text
G[i, r]
= sum over p, j, t of
    A[i, p] * X[p, j] * W_V[j, t] * W_O[t, r]
```

其中 `i` 是目标对象，`p` 是来源对象，`j` 是输入特征，`t` 是 value 特征，`r` 是输出特征。这个元素式足以证明：对象 `i` 的聚合分支可以依赖多个来源 `p`，另外两条分支则不会因此自动获得相同的跨对象依赖。

接下来检查三类接口：`A` 的来源列必须与 `X` 的对象行一一对应；三条分支的输出必须描述同一批目标对象；相加前的特征轴必须属于同一表示空间，而不只是长度碰巧相等。若 `A` 是读取权重，还要核对关系来源、归一化方向、非法来源和空来源边界；若它只是一般线性系数，就不能擅自解释为概率。

陌生公式的闭合阅读最终需要两层描述：局部层指出哪里变换特征、哪里使用关系、哪里逐元素处理；整体层说明输入怎样到达输出、哪些对象在何处交互、每个输出允许依赖谁。只列运算名称会得到操作清单，只讲整体故事又无法核验。轴、元素和依赖路径三者一致，才算恢复了模型模块的信息流。

下一章将把方向反过来：先给任务、权限和输出规格，再选择动作并设计公式。阅读是从符号恢复语义，设计则是从语义构造符号。
