# 第5章 投影、最小二乘与最佳近似

## 5.1 从 `y_hat = Xw` 追问模型能表达什么

第2章曾经读过：

```text
y_hat = Xw
```

若：

```text
X: 对象 × 特征
X: n × d
w: d × 1
y_hat: n × 1
```

那么：

```text
y_hat[i] = sum over j of X[i, j] * w[j]
```

表示第 `i` 个对象的全部特征被加权组合成一个预测值。当时我们只回答“给定 `w` 后，`Xw` 在做什么”，把另一个问题留了下来：面对真实目标 `y`，参数 `w` 应该怎样选择？

直觉上，我们希望：

```text
Xw = y
```

假设 `X` 记录 `n` 名学生的 `d` 项平时表现，`y` 记录每名学生的期末成绩。若能找到一个 `w`，让 `Xw` 与 `y` 完全相等，就意味着同一组特征权重准确产生了所有学生的目标成绩。

但这种精确表达未必存在。原因不一定是计算不够精确，也不一定是还没有找到足够聪明的算法。更根本的问题是：当 `w` 变化时，`Xw` 只能在一个受 `X` 限制的集合中变化。真实目标 `y` 可能根本不属于这个集合。

这里讨论的表达能力有明确边界：固定当前这 `n` 个样本以及由它们组成的设计矩阵 `X`，只让参数 `w` 变化。若更换样本、增删特征或改变特征构造，`X` 随之改变，可表达集合也会改变；那已经是另一个设计问题。

为了看见这个限制，把 `X` 按列写成：

```text
X = [x_1, x_2, ..., x_d]
```

其中每一列 `x_j` 都是一个长度为 `n` 的向量，记录第 `j` 个特征在所有对象上的取值。于是：

```text
Xw
= w[1] * x_1
+ w[2] * x_2
+ ...
+ w[d] * x_d
```

所以，`Xw` 是 `X` 的各列向量的线性组合。无论怎样改变 `w`，我们都只能重新组合这些列，不能凭空产生列向量无法表达的方向。

若模型还需要独立截距，可以把一列全1加入 `X`，将截距作为对应的参数分量；这样仍可统一写成 `Xw`。

这使“怎样选择 `w`”变成两个连续的问题：

```text
Xw 能够表达哪些向量？
如果 y 不在其中，哪个 Xw 最接近 y？
```

本章的所有概念——列空间、残差、投影、正交和正规方程——都从这两个问题依次产生。它们不是一组需要分别背诵的术语，而是同一个最佳近似问题的不同表述。

## 5.2 列空间：所有可能预测构成的集合

`X` 的列向量能够生成的全部线性组合，称为 `X` 的列空间，记作：

```text
Col(X)
```

根据刚才的展开：

```text
Col(X)
= {Xw | w ∈ R^d}
```

因此，列空间可以被直接解释为：

> 当特征矩阵 `X` 固定时，线性模型能够产生的全部预测向量。

这里容易出现一个轴上的误解。`X` 是 `n × d`，每一列的长度是 `n`，所以 `Xw` 和目标 `y` 都是长度为 `n` 的向量。标准地说，`Col(X)` 是 `R^n` 的一个子空间；从轴语义看，这个 `n` 维空间的每个坐标位置对应一个对象，一个点表示对全部 `n` 个对象给出的一整组输出。它不是每个对象自己的 `d` 维特征空间。

学生案例中，一列可以是所有学生的作业成绩，另一列可以是所有学生的测验成绩。用权重组合两列，会产生一条长度为 `n` 的预测向量：它同时给出所有学生的预测成绩。改变 `w`，就是改变各项平时特征整列进入预测的比例。

若 `X` 只有两列：

```text
X = [x_1, x_2]
```

那么所有预测都形如：

```text
Xw = w[1] * x_1 + w[2] * x_2
```

如果 `x_1` 和 `x_2` 指向两个独立方向，它们在高维空间中张成一个二维平面。`w[1]` 和 `w[2]` 决定预测向量在这两个方向上走多远。若两列本身存在重复或线性依赖，它们能够张成的空间还会更小。

于是，精确表达目标的条件可以写成：

```text
y is in Col(X)
```

若成立，就至少存在一个 `w` 使：

```text
Xw = y
```

若不成立，无论怎样调整 `w`，`Xw` 都不能碰到 `y`。此时继续追求等式成立已经没有意义，我们需要把问题改成：在 `Col(X)` 中寻找离 `y` 最近的向量。

这个转变很重要。模型训练不再被理解为“不断尝试直到公式等于目标”，而是“承认表达集合有限，并在其中寻找最好结果”。所谓模型的表达能力，在这里首先表现为列空间包含哪些方向。

还要区分预测向量与参数向量。`w` 位于参数空间中，`Xw` 位于对象坐标组成的输出空间中。不同的 `w` 可能生成不同预测；当 `X` 的列存在依赖时，不同的 `w` 甚至可能生成同一个 `Xw`。本章关心的几何投影首先发生在目标 `y` 与预测 `Xw` 之间，而不是把 `y` 直接投影成参数 `w`。

## 5.3 残差与距离：怎样定义“最好的近似”

当 `y` 不在列空间中，任意选择一个 `w` 都会留下差异。定义：

```text
r = y - Xw
```

向量 `r` 称为残差。它逐对象记录真实目标与预测之间的差：

```text
r[i] = y[i] - y_hat[i]
```

若 `r[i] > 0`，表示当前预测低于目标；若 `r[i] < 0`，表示当前预测高于目标。残差向量把所有对象的预测误差组织在一起。

要比较不同 `w` 的好坏，需要定义残差有多大。最小二乘采用残差的平方长度：

```text
||r||^2
= ||y - Xw||^2
= sum over i of (y[i] - y_hat[i])^2
```

于是最小二乘参数解的集合定义为：

```text
W_star
= argmin over w ∈ R^d of ||y - Xw||^2
```

这里 `argmin` 返回所有使目标函数达到最小值的参数，而不预先假定解唯一。任选一个：

```text
w_hat ∈ W_star
```

都产生最佳预测：

```text
y_hat = Xw_hat
```

最佳预测 `y_hat` 是唯一的，但当 `X` 列秩不足时，产生它的 `w_hat` 可以不唯一。

为什么使用平方？从几何上看，`||y - Xw||` 是目标点 `y` 到预测点 `Xw` 的欧氏距离；平方不改变哪个点最近，却让表达更方便。于是，最小二乘可以读成：

> 在所有可表达预测 `Xw` 中，寻找与目标 `y` 欧氏距离最近的一个。

“最小二乘”这个名字来自误差平方和，但它真正建立的是一个几何最近点问题。我们不是分别为每名学生任意修正预测，而是必须选择同一个参数向量 `w`，让整条预测向量在列空间中移动。各对象残差共同决定哪个位置最接近目标。

残差不是计算失败的同义词。若 `y` 不在 `Col(X)` 中，任何线性组合都会留下残差。它表示当前特征列无法解释的那部分目标。改变特征、加入新的表达结构，可能改变可表达集合；但在 `X` 固定时，最小二乘只能在现有列空间中选择最近点。

本章使用欧氏距离和平方误差来定义“最好”。其他任务也可能采用不同误差度量，并得到不同的最佳近似。这里不扩展损失函数体系，只关注最小二乘为什么与投影和正交自然连接。

## 5.4 投影与正交：最近点为何具有特殊方向关系

把 `Col(X)` 想象成空间中的一个平面，目标 `y` 是平面外的一个点。我们在平面上选择一个预测点：

```text
y_hat = Xw_hat
```

使它离 `y` 最近。这个最近点称为 `y` 在 `Col(X)` 上的正交投影。

投影关系可以写成：

```text
y = y_hat + r
```

其中：

```text
y_hat is in Col(X)
r = y - y_hat
```

几何上，残差 `r` 从投影点 `y_hat` 指向目标 `y`。为什么它必须与列空间正交？

假设残差在列空间上的投影仍不为零。那就意味着我们还能让 `y_hat` 在列空间中朝这个分量移动一点，使它更接近 `y`。只要这种可继续缩短距离的方向存在，当前点就不是最近点。真正到达最近点后，残差在列空间中的分量已经被消除，只剩垂直于列空间的部分。

因此：

```text
r is orthogonal to Col(X)
```

因为 `X` 的每一列都位于列空间中，残差必须与每个列向量正交：

```text
x_j^T r = 0
for every column x_j of X
```

把所有列的正交条件一次写出，得到：

```text
X^T r = 0
```

这条式子的轴也值得阅读。若：

```text
X: 对象 × 特征
r: 对象 × 1
```

那么：

```text
X^T: 特征 × 对象
X^T r: 特征 × 1
```

其中第 `j` 个元素是：

```text
(X^T r)[j]
= sum over i of X[i, j] * r[i]
```

它衡量残差与特征列 `j` 的内积。`X^T r = 0` 表示残差与每一列特征方向的内积都为零。

这给出了正规方程最核心的语义：

> 最优残差中，不再含有任何可以沿 `X` 的列方向继续吸收的分量。

标准地说，残差在 `Col(X)` 上的投影为零。

正交条件不仅是最近点的必要条件，也足以保证最近。若某个预测 `y_hat` 位于 `Col(X)` 中，且残差 `r = y - y_hat` 与列空间正交，那么对任意另一个预测 `Xw`：

```text
y - Xw
= r + (y_hat - Xw)
```

其中 `r` 与 `y_hat - Xw` 正交，因此：

```text
||y - Xw||^2
= ||r||^2 + ||y_hat - Xw||^2
>= ||r||^2
```

所以没有其他可表达预测比 `y_hat` 更接近 `y`。这也说明投影向量 `y_hat` 是唯一的；若 `X` 的列存在依赖，产生它的参数 `w_hat` 仍可能不唯一。

前面的直觉性表述需要谨慎理解。它不表示残差与每个原始特征在所有可能的统计意义上“完全无关”，也不表示模型已经解释了现实中的一切。它只表示在当前欧氏内积和当前特征矩阵下，残差与每个列向量正交。

如果 `y` 本来就在列空间中，投影就是 `y` 自身，残差为零；零向量当然与列空间正交。如果 `y` 不在列空间中，残差非零，但它指向模型无法通过调整 `w` 继续接近的方向。

## 5.5 从正交条件到正规方程

把：

```text
r = y - Xw_hat
```

代入正交条件：

```text
X^T r = 0
```

得到：

```text
X^T(y - Xw_hat) = 0
```

展开括号：

```text
X^T y - X^T Xw_hat = 0
```

整理为：

```text
X^T Xw_hat = X^T y
```

这就是最小二乘的正规方程。

不要把它先当作一条突然出现的求解公式。它只是“残差与列空间正交”的代数写法。左边和右边的形状都是：

```text
特征 × 1
```

其中：

```text
X^T X: 特征 × 特征
X^T y: 特征 × 1
```

第3章已经说明，`X^T X` 以两条特征轴组织数据。这里它不再只被读成特征关系矩阵，而是出现在一组关于参数 `w_hat` 的方程中。等式：

```text
X^T Xw_hat = X^T y
```

也可以改写为：

```text
X^T(Xw_hat) = X^T y
```

它表示最佳预测 `Xw_hat` 与各特征列形成的内积，和真实目标 `y` 与各特征列形成的内积相同。两边相减就是：

```text
X^T(y - Xw_hat) = 0
```

即残差对所有特征方向都不再留下可利用的内积分量。

正规方程本身不要求 `X^T X` 可逆；满足正规方程的参数正是最小二乘解，并且正规方程至少有一个解。可逆性只决定能否用下面的逆矩阵公式得到唯一参数。

如果 `X^T X` 可逆，可以写出：

```text
w_hat = (X^T X)^(-1) X^T y
```

但这条闭式解成立需要条件。`X^T X` 可逆，当且仅当 `X` 的列线性独立，也就是 `X` 具有满列秩；这还要求 `d <= n`。若特征列重复或存在依赖，逆矩阵公式不可用，但最优预测 `Xw_hat` 仍然存在且唯一，最优参数可能不唯一。此时可以采用能处理秩亏的其他求解方式，本章不展开具体算法。

因此，闭式解不是最小二乘思想本身。最小二乘首先定义最近预测，投影给出几何解释，正交条件导出正规方程；是否用求逆、分解或数值算法得到参数，是后续计算方法的问题。本书不在这里展开求逆技巧或数值稳定性。

还要注意，正规方程是最优性的条件，不是“让原方程变得精确”的魔法。若 `y` 不在列空间中，解出 `w_hat` 后仍有：

```text
Xw_hat != y
```

它保证的是：

```text
Xw_hat is the closest point to y in Col(X)
```

而不是把不可表达的目标强行变成可表达。

## 5.6 从向量目标推广到多输出近似

前面讨论的是每个对象一个目标：

```text
y: n × 1
```

若每个对象有 `k` 个目标，可以把它们并排放进矩阵：

```text
Y: 对象 × 目标
Y: n × k
```

参数也从向量扩展为矩阵：

```text
W: 特征 × 目标
W: d × k
```

预测为：

```text
Y_hat = XW
Y_hat: n × k
```

用 `q` 表示目标列，最小二乘目标可以写成：

```text
minimize over W: ||Y - XW||_F^2
```

这里 `|| · ||_F` 表示把矩阵中所有元素的平方相加后开方的 Frobenius 范数，因此：

```text
||Y - XW||_F^2
= sum over i, q of
  (Y[i, q] - Y_hat[i, q])^2
```

从列的角度看，多输出问题就是同时近似 `k` 个目标向量，因为：

```text
||Y - XW||_F^2
= sum over q of
  ||Y[:, q] - XW[:, q]||^2
```

其中 `q` 表示目标列。每一列满足：

```text
Y_hat[:, q] = X W[:, q]
```

因此，每个目标列 `Y[:, q]` 都在同一个列空间 `Col(X)` 中寻找投影。不同目标使用 `W` 的不同列，但共享同一个输入特征矩阵 `X`。这种按列分解来自当前采用的未加权 Frobenius 平方误差。

残差变成矩阵：

```text
R = Y - XW_hat
```

正交条件为：

```text
X^T R = 0
```

也就是：

```text
X^T(Y - XW_hat) = 0
```

正规方程相应变为：

```text
X^T XW_hat = X^T Y
```

这不是一套新的原理，只是把单个目标的投影并排写成矩阵。对于每个输出列，残差都与 `X` 的列空间正交。

若 `X` 列秩不足，正规方程可能有多个矩阵解 `W_hat`；但每个目标列在 `Col(X)` 上的正交投影唯一，因此预测矩阵 `Y_hat = XW_hat` 仍然唯一。参数非唯一不等于拟合结果非唯一。

多输出形式也为下一章建立了一条公式接口。本章对每个目标列使用同一个固定投影空间。若以 `Q` 表示 `Col(X)` 的任一正交标准基，`Q: n × r` 且 `Q^T Q = I`，则：

```text
Y_hat = Q Q^T Y
```

其中 `QQ^T` 是投到固定空间 `Col(X)` 的正交投影矩阵。下一章不再预先给定这个空间，而是从被近似数据自身选择一个 `k` 维空间，再做投影与重建；这将形成：

```text
固定空间中的投影：Y_hat = Q Q^T Y
从数据选择空间：   D_k = D V_k V_k^T
```

两者都用正交投影缩短平方距离，区别在于空间是已给定，还是也属于待选择的结构。

## 5.7 用几何、元素与公式解释同一个解

本章的因果链可以压缩为：

```text
固定样本与设计矩阵 X
-> 可表达集合 Col(X) = {Xw | w ∈ R^d}
-> 残差 r = y - Xw
-> 最小化 ||r||^2
-> 唯一最近点 y_hat 是正交投影
-> X^T(y - Xw_hat) = 0
-> X^T Xw_hat = X^T y
```

元素式：

```text
r[i] = y[i] - sum over j of X[i, j] * w_hat[j]
```

说明同一组权重在全部对象上留下怎样的差异；矩阵式把“残差与每个特征列正交”一次写完。`w_hat` 是产生投影的参数，不是投影本身；投影 `y_hat = Xw_hat` 唯一，参数只有在 `X` 满列秩时才唯一。最小二乘也不保证零残差，除非 `y ∈ Col(X)`。

因此，第5章解决的是“在固定空间中选最近点”。若 `Q` 是该空间的正交标准基，多输出投影为：

```text
Y_hat = Q Q^T Y
```

第6章将把空间本身也纳入选择。对被近似数据矩阵 `D`，它将寻找由前 `k` 个右奇异向量组成的 `V_k`，并得到：

```text
D_k = D V_k V_k^T
```

`QQ^T` 与 `V_k V_k^T` 都是正交投影矩阵。前者投向预先给定的可表达空间；后者对应从数据中选出的 `k` 维特征子空间。这就是从向量最小二乘到矩阵低秩近似的公式级接口。
