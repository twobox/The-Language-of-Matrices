# 第1章外部试读包：矩阵表达式的语义基础

本文件用于组织第1章的真实目标读者试读。它规定受试者条件、材料顺序、观察方式、反馈记录和暂定通过标准，使试读结果能够直接支持正文、练习、答案与图示修改。

本文件只提供试读方案与记录模板，不代表已经获得真实读者数据。实际结论必须来自受试者完成试读后的原始记录。

## 一、试读目标

本轮试读主要验证四件事：

1. 目标读者能否区分轴语义、轴长度和索引；
2. 能否同时检查矩阵乘法的数量接口与语义接口；
3. 能否通过元素展开和求和索引区分 `XW` 与 `AX` 的信息动作；
4. 能否把本章方法迁移到未见过的场景，而不依赖模型名称。

同时记录正文解释密度、练习难度梯度、图示独立性和完成时间。

## 二、目标受试者

优先邀请3—5名符合以下条件的读者：

- 学过基本矩阵乘法和转置；
- 能判断常见矩阵形状是否可以相乘；
- 阅读机器学习、数据分析或论文公式时，仍常停留在维度检查，难以解释轴语义与信息流；
- 没有参与本书的前期讨论或正文编写。

暂不优先选择矩阵建模经验非常丰富的研究者作为首轮受试者，因为他们可能凭既有知识跳过本章要验证的阅读步骤。可以另邀请1名高水平读者做准确性复核，但其结果应与目标读者试读分开记录。

不记录与试读无关的个人信息。受试者编号使用 `R1`、`R2`、`R3` 等匿名标识。

## 三、试读材料

按以下顺序提供材料：

```text
1. 章节/第01章.md
2. 图示/第01章.md 中的三张图示
3. 练习/第01章.md
```

试读过程中不提供《练习/第01章-参考答案与校准.md》。完成全部作答后，才可以使用参考答案进行评分和访谈。

若需要检验图示的独立解释能力，应把三张图单独导出或截取，避免受试者立即从相邻正文复制答案。

## 四、试读方式

### 1. 阅读阶段

让受试者独立阅读第1章正文和三张图示。允许划线和做笔记，不主动解释术语。

记录：

- 开始与结束时间；
- 首次停顿位置；
- 主动返回前文的位置；
- 明确说“看不懂”“不知道为什么”或产生错误解释的位置。

### 2. 练习阶段

让受试者依次完成8道练习。原则上不跳题；如连续停顿超过3分钟，可以先标记后继续。

观察者只在受试者明确无法继续时提供最小提示。提示分三级记录：

```text
0级：无提示
1级：提醒使用八步流程，不指出具体步骤
2级：指出应检查的维度，例如“请看共同轴”
3级：直接提供关键判断或部分答案
```

每道题记录：

- 用时；
- 首次错误；
- 是否返回正文或图示；
- 提示等级；
- 最终是否达到验收点。

### 3. 图示独立验证

练习结束后，单独展示三张图，依次提问：

**图1-1**

1. `n`、`i` 和“学生轴”分别是什么？
2. `X[i, j]` 中两个索引分别选择哪条轴上的位置？

**图1-2**

1. 为什么两个内侧长度都是 `d`，乘法仍可能没有合理语义？
2. 除了长度相同，共同轴还必须满足什么条件？

**图1-3**

1. `Y[i, r]` 是否直接读取其他对象的输入？依据是什么？
2. `Z[i, q]` 沿哪类对象求和？输出继续描述谁？

回答时不允许先返回正文。若无法回答，再记录其需要查看正文的具体位置。

### 4. 结束访谈

使用以下问题进行5—10分钟访谈：

1. 哪一处第一次让你意识到“维度正确不等于语义正确”？
2. 哪一道题最难？困难来自题意、符号还是概念？
3. 哪两道题感觉重复？为什么？
4. 三张图中哪一张最有帮助，哪一张信息最拥挤？
5. 你现在会怎样向别人解释 `XW` 与 `AX` 的差别？
6. 哪个术语仍然不自然或容易混淆？

不要只问“是否喜欢”或“是否看懂”，要追问具体位置和具体判断。

## 六、首轮暂定通过标准

以下标准用于首轮校准，不是最终出版标准：

### 核心能力

- 至少3名符合条件的目标读者完成全部试读；
- 练习1—5的大部分验收点能够在0—1级提示下完成；
- 练习6—8能够在不依赖模型名称的情况下完成核心判断；
- 至少三分之二的受试者能仅凭图示回答每张图对应的独立验证问题；
- 受试者能明确说明：`XW` 沿旧特征轴求和，`AX` 沿来源对象轴求和。

### 时间与难度

- 8道练习的中位完成时间应大致落在内部校准的55—70分钟附近；
- 若多数读者明显超过80分钟，应检查题目重复、文字负担或提示不足；
- 若多数读者少于40分钟且几乎没有停顿，应检查受试者是否过强，或题目是否缺少真正的迁移要求。

### 修改触发条件

出现以下任一情况，应进入修改而不是直接扩展后续章节：

- 两名及以上读者在同一表述处产生相同误解；
- 两名及以上读者只能通过2级或3级提示完成同一道题；
- 图示不能在脱离正文时支持对应判断；
- 练习7被普遍理解为需要掌握关系构造或归一化；
- 练习8被普遍通过套用模型名称完成，却无法说明求和索引和轴去向；
- 参考答案的评分点无法稳定覆盖读者的合理不同表述。

## 八、试读后的决策顺序

完成真实读者试读后，按以下顺序处理：

```text
1. 先修正事实、符号和题意歧义
2. 再修正重复出现的概念误解
3. 调整练习顺序、提示层级和验收点
4. 调整图示标注与正文插入位置
5. 重新核对参考答案和评分标准
6. 必要时进行第二轮小规模复测
7. 第1章闭环稳定后，再扩展第2—4章练习
```

不要因为单名读者的个人偏好立即大幅改写正文；优先处理跨读者重复出现、并能定位到具体文本或图示的问题。
