# 第1章练习：矩阵表达式的语义基础

## 使用方式

本组练习检验五项基础能力：标注轴语义、核对形状与接口、展开输出元素、追踪求和方向、诊断语义错误。除非题目另有说明，不需要进行大规模数值计算。

回答时不要只写“可以相乘”“维度不对”或“语义错误”。应指出具体是哪两条轴对接、哪个索引被求和、输出继续描述谁，以及错误发生在哪个接口或信息路径上。

建议完整作答时间为55—70分钟。也可以把练习1—5作为基础组，练习6—8作为综合组分两次完成。

## 练习1：区分轴、长度与索引

某矩阵 `X` 保存120名学生在6门课程上的成绩。

### 任务

分别写出 `X` 的轴语义、形状，并为两条轴选择索引符号。解释 `X[i, j]` 的含义。

### 提交物

```text
X: ______ × ______
X: ______ × ______

i：______
j：______

X[i, j]：______
```

### 验收点

- 能区分“学生轴”与长度120、“课程轴”与长度6。
- 索引表示轴上的位置，而不是轴长度。
- 元素解释同时包含学生和课程两个角色。

## 练习2：相同形状是否代表相同语义

有两个矩阵：

```text
A: 50 × 12
B: 50 × 12
```

其中 `A` 表示“用户 × 月份”，`B` 表示“商品 × 地区”。

### 任务

说明为什么仅凭形状不能认为 `A` 与 `B` 是同一种数据。进一步判断表达式 `A + B` 虽然在数值形状上可执行，是否已经具有明确语义。

### 提交物

用一段话分别回答：

1. 两个 `50 × 12` 中，每个长度对应什么轴；
2. 加法需要满足什么语义条件；
3. 当前信息为何不足以支持有意义的逐元素相加。

### 验收点

- 不把轴长度相同等同于轴语义相同。
- 指出逐元素运算也要求对应位置代表同一类实体和属性。
- 结论包含具体冲突，而不是只说“语义不一致”。

## 练习3：检查相乘接口

设：

```text
X: 学生 × 课程
X: n × d

W: 课程 × 能力指标
W: d × k

V: 城市 × 收入等级
V: d × k
```

这里课程数与城市数恰好都等于 `d`。

### 任务

分别判断 `XW` 与 `XV`：

1. 在形状上是否可计算；
2. 相乘接口分别连接哪两条轴；
3. 在当前定义下是否具有合理语义。

### 提交物

完成下表：

| 表达式 | 形状检查 | 共同轴的两侧语义 | 语义判断 |
|---|---|---|---|
| `XW` |  |  |  |
| `XV` |  |  |  |

### 验收点

- 对 `XV` 同时承认“形状合法”和“接口语义不成立”。
- 明确指出课程轴不能仅因长度相同就与城市轴逐项对应。
- 不把“转置一个矩阵”当作自动修复方法。

## 练习4：展开一个输出元素

设：

```text
X: 学生 × 课程
X: n × d

W: 课程 × 能力指标
W: d × k

Y = XW
```

### 任务

写出 `Y` 的轴语义和形状，展开 `Y[i, r]`，并把它翻译成自然语言。

### 提交物

```text
Y: ______ × ______
Y: ______ × ______

Y[i, r] = ______

自然语言：______
```

### 验收点

- 求和索引是课程索引，而不是学生索引。
- 自由索引 `i` 与 `r` 出现在输出位置中。
- 自然语言说明“为哪名学生计算哪个能力指标，以及读取哪些成绩”。

## 练习5：追踪轴的去向

对一般矩阵乘法：

```text
A: P × Q
B: Q × R
C = AB
```

### 任务

写出一个典型输出元素，并判断 `P`、`Q`、`R` 三条轴在运算中的去向。

### 提交物

```text
C: ______ × ______
C[i, r] = ______

被汇总的轴：______
从左输入进入输出的轴：______
从右输入进入输出的轴：______

求和索引：______
自由索引：______
```

### 验收点

- `Q` 轴通过共同索引被遍历和求和。
- `P` 与 `R` 对应输出中的两个自由索引。
- 不把 `P`、`Q`、`R` 与它们的长度符号混为一谈。

## 练习6：比较两种求和方向

设：

```text
X: 对象 × 旧特征
W: 旧特征 × 新特征
Y = XW

A: 目标对象 × 来源对象
H: 来源对象 × 特征
Z = AH
```

### 任务

分别展开 `Y[i, r]` 与 `Z[t, q]`，比较两者的求和轴、保留轴和信息来源。

### 提交物

用不超过六句话完成比较，必须包含：

- `XW` 沿哪条轴求和；
- `AH` 沿哪条轴求和；
- 两个输出分别继续描述谁；
- 哪一个表达式会直接混合不同对象的信息。

### 验收点

- 能区分“改变描述方式”和“改变信息来源”。
- 判断依据来自元素展开，而不是只凭左乘或右乘。
- 明确 `XW` 在该局部步骤中不读取其他对象的行。

## 练习7：诊断任务与公式是否匹配

任务要求：为每名学生按给定关系汇总其他学生在同一组课程上的信息。现有学生表示为：

```text
X: 来源学生 × 课程
X: n × d
```

候选关系矩阵和参数矩阵为：

```text
A: 目标学生 × 来源学生
A: n × n
A[i, i] = 0

W: 课程 × 新特征
W: d × k
```

其中 `A[i, p]` 非零表示目标学生 `i` 可以读取来源学生 `p` 的信息；对角线为零表示不读取自身。

有人提出三个候选表达式：

```text
方案一：Y = XW
方案二：Y = AX
方案三：Y = AW
```

### 任务

逐一判断每个方案的形状与任务语义，并选出能够直接完成“按学生关系汇总同一课程信息”的最小表达式。

### 提交物

对每个方案写出：

1. 是否形状合法；
2. 若合法，求和轴是什么；
3. 是否实现任务；
4. 错误方案的具体断点。

### 验收点

- 识别 `AX` 的共同轴是来源学生轴。
- 说明 `XW` 只对课程轴求和，未实现学生间汇总。
- 说明 `AW` 的接口在一般情况下不成立，而不是笼统判错。

## 练习8：陌生场景迁移

某监测系统记录设备的信号：

```text
U: 设备 × 原始信号
U: m × d

V: 原始信号 × 告警指标
V: d × k

M = UV
```

### 任务

不使用“这就是线性层”之类的模型名称，按照本章八步流程解释 `M = UV`。最后回答：仅凭这些轴与形状，哪些事实仍然无法确定？

### 提交物

至少包含：

- 三个矩阵的轴语义与形状；
- 相乘接口；
- 一个输出元素展开；
- 求和索引与自由索引；
- 一句完整自然语言解释；
- 至少两项无法仅由公式确定的信息。

### 验收点

- 能把阅读方法迁移到正文未使用的设备场景。
- 不依赖模型名称替代语义解释。
- 无法确定的信息可以包括参数如何得到、告警指标的具体含义、输出如何被后续使用等，但不能否认公式已经明确给出的轴与求和方向。

## 本章完成标准

完成本组练习后，读者应能在陌生的二维矩阵乘法中稳定回答以下问题：

```text
每条轴代表什么？
每条轴有多长？
哪两条轴构成相乘接口？
哪个索引被求和？
哪些索引留在输出？
输出在为谁计算什么？
公式的形状、语义和任务目标是否一致？
```
